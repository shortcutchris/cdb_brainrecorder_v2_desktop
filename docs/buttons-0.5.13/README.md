# Einheitliche Buttons – 0.5.13

Alle unteren Einstellungsaktionen verwenden eine gemeinsame Breitenvariable: 208 px bei 1280 × 720. Höhe 56 px, Abstand 12 px. Links bleibt Platz für Hilfsaktionen; die übrigen Aktionen stehen rechts in festen Positionen. Auf kleineren Ansichten werden die Breiten gemeinsam reduziert. Die beiden Breadcrumb-Stufen sind jeweils 160 px breit. Nummerierte Seitentasten behalten ihre quadratische Touchform.

Geprüft in der isolierten Pi-Vorschau: Brain-Konto, Audio, Vorlagen, Design, Themeeditor, Transkriptionsmodell und Diagnose. Alle 17 sichtbaren Aktionsbuttons: 208 × 56 px, y=624, kein Textüberlauf. Messwerte in `measurements.json`. 37 JavaScript-Tests bestanden; keine Verarbeitungslogik geändert. Screenshots sind Layoutnachweise, keine neue Modellmessung.
